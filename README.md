## 💡 Featured Projects — Click to Expand

<details>
<summary><b>🦯 V2T-Graph — Monocular Camera-to-Tactile/Audio Navigation System</b></summary>
<br/>

Real-time object detection, depth estimation & adaptive scene-graph pruning for visually impaired assistance.

- Designed a monocular navigation pipeline converting a single camera feed into real-time tactile and audio cues, combining YOLOv10 object detection with Depth Anything V2 monocular depth estimation
- Built an adaptive scene-graph module that prunes and prioritizes detected objects by proximity and navigational relevance, reducing cue clutter and latency
- Fused detection and depth outputs into a unified scene graph driving directional audio/tactile alerts for low-latency, hardware-light deployment

`PyTorch` `YOLOv10` `Depth Anything V2`

</details>

<details>
<summary><b>🌐 Speak Local, Understand Global — Offline Live Speech Translation & Captioning</b></summary>
<br/>

Internet-independent, locally-hosted live speech translation & accessible captioning.

- Built a fully offline, presenter-device-hosted speech translation and captioning system broadcast over a self-hosted WiFi hotspot, keeping all data on the local network
- Designed for accessibility: deaf and hard-of-hearing attendees get real-time, high-contrast captions, while blind and visually impaired attendees can listen to a live spoken translation

`Python` `FastAPI` `faster-whisper` `NLLB-200` `WebSockets` `asyncio`

</details>

<details>
<summary><b>🔥 AGNI — Confidence-Gated Multi-Agent Forecasting & RAG Pipeline</b></summary>
<br/>

Disaster-preparedness forecasting for heatwave response, backtested against historical IMD heatwave records.

`Multi-Agent Systems` `RAG` `LangGraph`

</details>

<details>
<summary><b>🚀 SAFIR — ML Surrogate for Rocket Fin Design Optimization</b></summary>
<br/>

ML surrogate model for design optimization and factor-of-safety classification, built on FEM/CFD simulation data from SimScale.

`ML Surrogates` `FEM/CFD` `SimScale`
